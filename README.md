# Ticketing system

Next.js frontend, Express/Prisma backend, PostgreSQL ticket data, Redis cache, and Supabase attachments.

For the DBMS Level 3 evaluation, start with [the demonstration runbook](docs/DBMS_EVALUATION_RUNBOOK.md) and [ER diagram and relational schema](docs/ER_AND_RELATIONAL_SCHEMA.md). The executable SQL demonstration is in `backend/demo/run-demo.mjs`; its generated DDL and additional database routines are in the same directory.
